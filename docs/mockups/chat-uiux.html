This pass (motion, icons, type, access)

  • The running command has one band of light across the whole line, verb and command together. The app's painter already shades by the glyph across one text box, so the build keeps "Running" and the command in one box.
  • Motion: menus open from their button in 180 ms and close in 120 ms. Opened or closed from the keyboard, they show at once. Buttons shrink slightly when pressed. Panels slide on the drawer curve in 280 ms. New messages rise in. Folder groups and command output fold smoothly.
  • Tooltips wait a moment the first time, then show at once while you move along a row of buttons. Icon-only buttons (tabs, ⋯, ✕, Copy, Try again) all have one.
  • Icons are Lucide's, at one stroke weight. The tool logos are Hover's own marks (Kiro, Codex, Claude).
  • A session at work has a ring spinning round its logo, as in the notch. One waiting on you has a breathing amber ring. The dots are gone.
  • Text: grey text is a little brighter, so the smallest text passes WCAG AA contrast. Nothing is smaller than 11 px. Code uses Cascadia Code, as the chat does.
  • Focus rings show for keyboard use only. With reduced motion on, nothing moves, only fades.
  • The send button stays grey until something is typed. While the agent works it is Stop, and turns back into Send (to queue) once you type.

Chat view

  • Header: title, then quiet chips for branch and context. Only ⋯ and ✕ on the right. The folder is in the reply box, beside +.
  • ⋯ holds Open in (the editors found on this computer, then the file manager), Terminal, Files & changes, Switch agent, Fork, and Delete.
  • In the reply box, @ adds a file from the folder as a chip, and / lists the agent's commands and Hover's.
  • Files: a Markdown file opens as a preview (or its Markdown), every file has Edit (Ctrl+S saves, Esc cancels) and Open in.
  • Commands: one line each, "Ran git switch main", with exit code and time at the right. A click opens the output.
  • A queued reply has Edit and Send now under it. No Cancel.
  • Files & changes is attached at full height and shows only the tabs this computer can use.
  • Model picker: each model's credit rate, the effort, and the auto compact line.

Office card

  • Header: the title, with the folder and context in grey under it. Only ⋯ and ✕.
  • The reply circle stays and says "Reply to Nova" under the pointer. A click or a typed key opens the reply box.
